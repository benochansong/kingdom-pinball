# KINGDOM PINBALL

**Bounce, Build, Conquer!** — GREENWOOD KINGDOM에서 플레이하는 중세 판타지 핀볼. PHASE 1 코어 엔진, PHASE 2 경제, PHASE 3 왕국 건설, PHASE 4 군대·훈련, PHASE 5 독립 왕국 전쟁, PHASE 6 마법·멀티볼, PHASE 7 대륙 정복 캠페인과 PHASE 8 반복 플레이 모드를 구현했습니다.

전쟁은 메인 메뉴의 **KINGDOM WAR**에서 시작합니다. 5개 적 왕국, 3개 전쟁 유형, 실제 경제와 생산에 기반한 침공, 성벽·왕궁 파괴, 수리·재건 및 별도 저장을 지원합니다. L 지휘소, 1~7 명령, U 군대, F 진형, B 준비 건설. [구현·검증·성능 한계](docs/PHASE5.md)를 참고하세요.

마법은 실제 시설·왕국 등급·연구로 해금합니다. ZXCV 스피어, G/H 주문, J 멀티볼, K CORE STORM, Tab 연구·편성. 메인 메뉴의 MAGIC TRAINING은 실제 왕국과 분리된 6개 연습 전장입니다. [마법 구현·검증](docs/PHASE6.md).

캠페인은 **NEW CAMPAIGN / CONTINUE CAMPAIGN**에서 시작합니다. 8개 지역·24개 스테이지, 분기 해금, 지역 장치와 보스, 3개 저장 슬롯, 영토·연구·장군·장비, 엔딩과 별도 슬롯 NG+를 제공합니다. [캠페인 구현·검증·성능 제한](docs/PHASE7.md).

**GAME MODES**에서 생존·샌드박스·8보스 러시·30퍼즐·3막 로그라이크·테이블 제작기·일일/주간 도전·사용자 정의 전쟁·AI 관전을 선택합니다. 모드별 저장, 프로젝트 10슬롯, 프로필·칭호·외형을 제공합니다. [모드 구현·검증·제한](docs/PHASE8.md).

## 실행

PHASE 9는 지역·건물·병력 연출, 상황별 합성 음악과 채널 믹서, SIMPLE/ADVANCED HUD, 키 매핑·고대비·품질 설정을 추가합니다. [구현 및 제한](docs/PHASE9.md), [자산 권리](ASSET_LICENSES.md), [실제 렌더 측정](docs/visual-performance.json)을 참고하세요. 대규모 150기+10공은 해당 개발 환경에서 약 18FPS로 목표에 미달했습니다.

Node.js 20.19+ 또는 22.12+가 필요합니다. 개발에는 Node 24를 사용했습니다.

```sh
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 엽니다. 기본 주소는 `http://127.0.0.1:5173`입니다.

```sh
npm test
npm run typecheck
npm run build
npm run preview
```

`dist/`를 정적 호스팅에 배포할 수 있습니다. 서버·계정·외부 API가 필요하지 않습니다. 모든 그래픽은 Canvas, 사운드는 Web Audio로 생성합니다. 외부 폰트나 음원 요청이 없습니다.

## 조작

| 키                  | 동작                      |
| ------------------- | ------------------------- |
| A / ←               | 왼쪽 플리퍼               |
| D / →               | 오른쪽 플리퍼             |

하단 포인터 버튼으로도 양쪽 플리퍼와 발사대를 조작할 수 있습니다. 포커스를 잃으면 자동으로 멈춥니다.

## PHASE 1

- 600×900 논리 좌표, 240Hz 고정 스텝 Matter.js 물리. 최대 속도와 프레임 누적 상한으로 충돌 안정성을 유지합니다.
- 회전축을 중심으로 움직이는 플리퍼. 회전 표면의 상대 속도와 접촉 법선으로 충격량을 계산합니다. 끝부분 타격이 강하며 조준 방향은 접촉 지점과 타이밍에 따라 달라집니다.
- 오른쪽 스프링 발사대, 상단 유도 통로, 역류 방지 게이트, 슬링샷, 비대칭 범퍼 6종.
- 5개 스피어, 손실·재생성, 게임 오버, 재시작, TILT, 공 끼임 자동 복구.
- 점수 콤보, 4종 범퍼를 맞힌 후 활성화되는 보물 상자, 왕궁 5회당 +3,000점.
- 한국어 UI, 튜토리얼, 최고/최근 기록, 버전이 있는 오류 복구형 LocalStorage 저장.
- 음악/효과음 개별 음량, 음소거, 잔상/파티클/화면 진동 설정.
- 프로시저럴 왕국 테이블, 성벽, 왕궁, 숲·광산·수정, 금속 스피어와 충돌 효과.

## 구조

```text
src/
  core/       게임 상태, 타입이 지정된 충돌 이벤트 버스
  physics/    Matter.js 월드, 회전 플리퍼 접촉 계산
  systems/    점수, 콤보, TILT, 복구, 저장
  economy/    자원 거래, 생산, 시장, 목표, 발전 등급, 경제 저장
  scenes/     Phaser 렌더링, 독자적인 Canvas 테이블 아트
  audio/      Web Audio 음악·효과음
  effects/    제한된 파티클, 점수 팝업, 잔상
  ui/         HTML HUD, 메뉴, 모달
  data/       테이블 정의, 문자열, 튜토리얼
  config/     물리 밸런스
tests/        모델·물리 회귀 테스트
```

물리·게임 규칙·렌더링을 분리했습니다. `EventBus`의 유효 `hit`/`production` 이벤트가 이후 건설/전투 기능의 연결 지점입니다. 벽의 위치, 범퍼 점수, 물리 설정은 데이터 파일에서 조정합니다. 경제 밸런스는 `src/config/economy.ts`, 경제 목표는 `src/economy/ObjectiveManager.ts`에서 관리합니다.

## 두 가지 모드

**CLASSIC PINBALL**은 5개의 공으로 점수에 도전합니다. 경제 HUD와 비용이 없으며 기존 최고 점수·최근 원정·설정을 그대로 유지합니다.

**KINGDOM DEVELOPMENT**는 NEW KINGDOM으로 시작하고 CONTINUE KINGDOM으로 이어갑니다. 새 왕국은 확인 후 기존 왕국을 기록에 보관하고 초기화합니다. 최근 10개 왕국의 발전 기록을 별도로 확인할 수 있습니다.

### PHASE 2 구현

- 여섯 자원과 고유 시설: 벌목장, 채석장, 금광, 농장, 마력 수정탑, 코어 충전소.
- 접촉 법선 방향의 상대 속도에 따른 다섯 단계 생산 강도. 접근 속도 40px/s 이하와 유효하지 않은 충돌은 생산하지 않습니다.
- 점수와 독립적인 4초 생산 콤보, 특수 생산 콤보 5종, 생산 이벤트 5종, 왕궁의 ROYAL PROSPERITY.
- 시설별 READY/ACTIVE/BONUS/OVERLOADED/RECOVERING 상태. 반발 물리는 유지하면서 과부하 시 생산량 감소.
- 시설 1~5레벨, 레벨별 그래픽 장식·생산량 변화, Lv.3 회복 가속, Lv.4 과부하 저항.
- 창고 1~5레벨, 용량 초과 차단, 80% 안내와 초과 생산량 통계. 코어 에너지는 별도 용량.
- 왕실 시장의 1회·5회·최대 거래, 비용/수령량 미리 보기, 전체 거래 조건을 확인한 후 원자적으로 반영.
- 코어 에너지 재발사, 금화/마력석 복구, 자원이 모두 부족하면 경제 결과 화면.
- 5단계 왕국 발전 등급, 13개 경제 목표와 한 번만 수령하는 보상, 최근 자원 내역·생산 통계·플레이 스타일.
- 모든 관리 메뉴에서 물리, 콤보, 이벤트, 과부하, 쿨다운 시간이 함께 정지.
- 시설별 파티클, 획득량 팝업, HUD 이동 효과. 그래픽 효과는 물리 객체와 분리.
- 실제 행동에 반응하는 경제 튜토리얼, 다음 안내/건너뛰기/다시 보기.
- 작은 화면에서는 측면 패널을 숨기고 **왕국 현황**에서 등급·콤보·목표·특수 콤보에 접근합니다. 물리 좌표는 변하지 않습니다.

### 초기 밸런스

| 자원        | 초기 보유 | 초기 용량 | 일반 강도 기본 생산 |
| ----------- | --------: | --------: | ------------------: |
| 목재        |        50 |       500 |                  10 |
| 석재        |        30 |       500 |                   8 |
| 금화        |        50 |     1,000 |                   6 |
| 식량        |        30 |       500 |                  12 |
| 마력석      |         0 |       100 |                   3 |
| 코어 에너지 |       100 |       100 |                   5 |

- 첫 발사는 무료. 손실 후 버튼을 눌러 에너지 20을 소비합니다. 에너지 부족 시 금화 30 또는 마력석 8로 에너지 20을 회복합니다.
- 시설 강화 비용: 목재/석재/금화 각각 `50/30/40 → 100/70/80 → 200/140/160 → 350/250/300`.
- 시설 배율: `1 / 1.25 / 1.6 / 2 / 2.5`. 창고 용량 배율: `1 / 2 / 4 / 7 / 10`.
- 생산 강도 배율: `0.5 / 1 / 1.25 / 1.5 / 2`, 상대 법선 속도 경계 `180 / 420 / 700 / 1000px/s`.
- 생산 콤보: `1~2 ×1, 3~4 ×1.2, 5~9 ×1.5, 10~19 ×2, 20+ ×3`. 레벨·강도·콤보·이벤트를 곱한 **최종 배율 상한은 ×8**입니다. 최종 지급은 정수 내림입니다.
- 시설 생산 대기시간 420ms. 기본 과부하는 8초 안에 7회, 회복 7초, 생산량 25%. Lv.3부터 회복 시간 20% 감소, Lv.4부터 허용 타격 +3.
- 특수 콤보 공통 재사용 20초. MINING MASTER는 다른 생산시설 없이 채석장↔금광을 교대로 4회, HARVEST FESTIVAL은 12초 내 농장 5회, KINGDOM PROSPERITY는 15초 내 여섯 시설입니다.
- 유효 생산 18회, 특수 콤보 또는 목표 보상이 생산 이벤트를 유발합니다. 동시에 하나만 활성화되며 왕궁 보너스는 15초 지속 시간을 갱신합니다.
- 발전 등급용 누적 생산은 **실제 저장된 시설 생산량**입니다. 시장 구매·특수 보상·창고 초과분은 포함하지 않습니다.

### 저장과 이어하기

클래식 `kingdom-pinball:v1`과 경제 `kingdom-pinball:economy:v2`를 별도로 저장합니다. 경제 v1 필드 마이그레이션, 잘못된 값 정리와 기본값 복구를 지원합니다.

경제 모드는 유효 생산, 강화, 거래, 목표 보상, 발사/손실/재발사와 5초 체크포인트마다 저장합니다. 공의 좌표는 복원하지 않습니다. **발사 전 `inflight` 상태를 먼저 저장하므로 비행 중 새로고침하거나 메뉴로 나갔다 이어하면 공 손실로 처리되고 유료 재발사가 필요합니다.** 이미 비용을 낸 발사 대기 상태는 다시 비용을 내지 않습니다. 정상적인 끼임 복구·발사 통로 회수는 무료입니다.

다른 탭에서 저장이 변경되면 기존 탭을 일시정지하고 최신 저장을 불러오도록 안내합니다. 계정·클라우드 저장 기능은 없으며 브라우저 데이터를 지우면 기록이 사라집니다. 개발자 도구로 LocalStorage를 직접 변조하는 행위까지 막는 서버 기반 보안은 제공하지 않습니다.

## 검증과 한계

상세 실행 결과는 [docs/VALIDATION.md](docs/VALIDATION.md)를 참고하세요. PC 브라우저가 우선 대상입니다. 390×844 브라우저 화면 배치는 확인했지만 터치 입력은 보조 기능이며 모바일 실기기 최적화는 별도 검증이 필요합니다. 렌더링은 60FPS를 목표로 하지만 여러 하드웨어에서 성능 벤치마크한 결과는 아닙니다. 정밀 캐치·패스의 난이도와 1~20분 경제 성장 속도는 사용자 플레이테스트로 계속 조정해야 합니다.

장시간 프레임 정지 후에는 최대 150ms만 시뮬레이션해 과도한 따라잡기를 방지합니다. 따라서 백그라운드/성능 저하 중 현실 시간과 게임 시간이 다를 수 있습니다.

## 도메인과 배포

현재 게임은 상대 경로로 실행되어 도메인 설정이 필요하지 않습니다. 개발 도메인은 소스에 하드코딩하지 않습니다. 향후 절대 URL·OAuth·서버 기능을 추가할 때 `APP_DOMAIN`/`APP_ORIGIN` 기반 중앙 설정과 `.env.example`, 배포 환경 변수 문서를 함께 추가해야 합니다. DNS나 프로덕션 라우팅은 이 작업에서 변경하지 않습니다.

## PHASE 3 — 왕국 건설

왕국 모드에서 **B / 건설**로 진입합니다. 23종 시설을 경제·운영·물리·마법·군사로 분류했습니다. 10px 그리드에서 마우스 미리보기·클릭 배치 또는 X/Y 입력 후 확정할 수 있습니다. Q/E 회전(반사판·성벽 15°, 일반 건물 90°), 유료 이동, Lv.1~5 강화, 실제 투자금의 50% 철거 환급, Ctrl+Z로 직전 건설 거래의 정확한 되돌리기를 지원합니다. 플레이 재개 뒤에는 되돌릴 수 없습니다.

- 기존 고정 생산시설과 클래식 테이블은 유지합니다. 추가 생산시설은 개별 ID·레벨·과부하·생산 기록을 가지며 기존 생산 계산을 재사용합니다.
- 목재/석재 반사판, 강화 범퍼, 방향성 가속 장치, 최소 속도를 지키는 감속 장치, 방향 유도 장치, 마법탑·반사탑·에너지 제단이 실제 물리에 작용합니다. 제단은 5회 유효 타격 후 에너지 5 이상, 30초 재사용 제한을 적용합니다.
- 왕국 등급별 추가 건물 한도 4/8/12/16/20, 5개 영토, 종류별 건설 한도, 동일 종류 추가 비용 25% 증가가 적용됩니다. 실제 수용 가능 수는 안전한 공간에 따라 더 작을 수 있습니다.
- 회전 충돌 영역 검사, 현재 공 보호, 최소 30px 통로, 그리드 연결성·폐쇄 공간·주요 시설 접근성 검사에 이어 3종 발사 강도의 실제 Matter 시뮬레이션을 실행합니다. 표본 시험이 모든 미래 궤적을 보장하지는 않으며 기존 끼임 복구를 유지합니다.
- **TEST BALL**은 별도 Matter 공간으로 동작합니다. 실제 공 객체·위치·속도·경제 타이머를 수정하지 않으며 점수·자원·에너지 보상이 없습니다. Space/A/D 조작과 R 무료 재발사, 속도·충돌·끼임 표시를 제공합니다. 테스트 사용 여부만 건설 목표에 기록합니다.
- 주변 190px 기준 5개 조합, 건물 구성 기반 왕국 특성, 16개 일회성 건설 목표, 추천 설계 4종, 프리셋 3개를 지원합니다. 프리셋은 건설·강화·이동 비용을 미리 보여주며 기존 추가 건물은 유지합니다.
- 저장 payload 버전은 3으로 확장했으며 기존 `kingdom-pinball:economy:v2` 키를 유지해 v1/v2 데이터를 자동 변환합니다. 건물의 논리 데이터만 저장하고 물리 객체는 복원합니다. 잘못된 건물만 제외하며 복구 개수를 알립니다.

주요 모듈: `src/building/BuildingManager.ts`, `PlacementValidator.ts`, `BuildingPhysicsAdapter.ts`, `TestBallSimulator.ts`, `PhysicsSafetyProbe.ts`, `BuildingSave.ts`, `src/config/buildings.ts`, `src/ui/BuildUI.ts`. 배치·업그레이드·물리·저장·UI를 분리해 PHASE 4 군사시설이 같은 건물 ID와 거래 흐름을 재사용합니다.

PHASE 4에서는 아래 군대 시스템을 같은 자원·건물 관리 흐름에 연결했습니다. 공성전, 캠페인, 특수 스피어와 멀티플레이는 이후 단계의 범위입니다.

## PHASE 4 — 왕국의 군대

왕국 모드에서 **B로 병영 건설 → U로 유료 훈련 등록 → 창을 닫고 생산 진행 → 군사 훈련에서 연습 또는 도전** 순서로 이용합니다. 군대 패널의 병력 생산·편성·연구·훈련·목표 탭에서 상태를 확인할 수 있습니다. **1 공격 / 2 방어 / 3 위치 유지 / 4 후퇴 / 5 재집결 / F 진형 / U 군대**를 지원하며 화면 버튼도 제공합니다.

| 시설 | 기능 / 병력 |
| --- | --- |
| 병영 | 등급 1 검병, 등급 2 창병, 등급 3·시설 Lv.2 방패병 |
| 궁수 훈련장 | 등급 2 궁수 |
| 마구간 | 등급 3 기병, 첫 공격 돌격 추가 피해 |
| 마법학교 | 등급 4 마법사, 광역 마법과 마법 연구 |
| 신전 | 등급 4 치유사, 제한적 타격 회복과 치유 연구 |
| 공성 작업장 | 등급 5 투석기, 장거리 곡사 광역 공격 |
| 대장간 / 군사학교 | 무기·방어 / 전술 연구 |
| 궁수탑 / 감시탑 / 성벽 | 자동 원거리 공격 및 타격 강화 / 접근 경보 / 실제 길찾기 장애물 |
| 군량 창고 | 레벨당 인구 한도 +5, 전체 최대 120 |

건물은 기존 23종에 7종을 추가한 총 30종입니다. 군사시설도 기존 건설·이동·회전·강화·철거와 저장 검사를 재사용합니다.

### 생산과 성장

- 검병·창병·궁수·방패병·기병·마법사·치유사·투석기 8종. 비용, 체력, 공격, 방어, 사거리, 속도, 생산 시간과 인구는 `src/config/army.ts`에서 조정합니다.
- 비용은 등록할 때 한 번 지불합니다. 1기/5기/가능한 최대, 자동 생산, 순서 변경, 취소를 지원합니다. 취소는 **실제 지불액 × 미진행률 × 50%**를 자원별 내림하여 환급합니다.
- 생산 대기열은 시설 레벨별 5/6/7/8/10, 속도는 1/1.2/1.4/1.7/2배입니다. 인구 예약을 포함해 한도를 검사하며 이미 지불한 병력만 타격으로 15~30% 가속합니다. 출구가 막히면 완료 상태로 대기합니다.
- 기본 인구 한도 15/25/40/60/80. 병력 인구 10당 식량 3을 30초마다 소비합니다. 부족하면 신규 등록을 제한하고 60초 유예 뒤 사기가 감소합니다. 부족만으로 병사가 즉사하지 않습니다.
- 사기 0~100, 기여 기반 경험치와 5개 계급, 기존·신규 병력 모두에 적용되는 5종 3단계 연구, 일회성 군사 목표 17개를 제공합니다.

### 전투와 핀볼 지원

병사는 Matter body를 만들지 않습니다. 건물·고정 시설·벽을 반영한 10px 내비게이션 그리드와 최대 64개 공유 경로장을 사용하고, 공간 버킷으로 근처 부대와 분리합니다. 전투는 20Hz, 핀볼은 기존 240Hz 고정 스텝입니다. 인접 공격·화살·마법 광역·치유·기병 돌격·투석기 곡사 공격, 공격 예고·쿨다운·사망·후퇴를 처리합니다. 병사가 서 있던 자리에 건물을 지으면 재개할 때 가장 가까운 이동 가능 지점으로 복구합니다.

검병→창병, 창병→기병, 궁수→창병, 기병→궁수/마법사, 마법사→방패병 상성과 방패병 원거리 저항이 적용됩니다. 기본·방패벽·대기병·돌격·원거리·공성 6개 진형은 실제 배치 순서와 공격/방어/사거리에 영향을 줍니다.

스피어의 이전 위치부터 현재 위치까지 선분을 검사해 고속 관통 누락을 줄입니다. 적에게 속도별 5/15/25/40/60 피해, 적별 550ms 중복 제한, 고속 기절과 작은 밀침을 적용합니다. 아군은 피해나 물리 충돌을 받지 않습니다. 일시정지·건설·TEST BALL·TILT·자동 복구 중에는 직접 피해를 주지 않습니다.

군사 콤보 7종은 생산 가속·공격/방어 강화·치유·다음 돌격/마법 강화에 연결됩니다. 동시 최대 3개, 개별 재사용 30초, 지속 시간이 적용됩니다. 평상시/군대 보유/전투/격전 음악 템포와 제한된 동시 효과음, 병종별 벡터 그래픽을 제공합니다.

### 훈련과 저장

5개 시나리오(BASIC COMBAT, RANGED DEFENSE, CAVALRY ASSAULT, COMBINED ARMS, 2차 파동과 지휘관이 있는 ROYAL CHALLENGE)를 제공합니다. 전투 제한 시간은 4분입니다.

- **연습 전투:** 경제·군대·건물의 복사본과 별도 핀볼 공간으로 실행합니다. 종료 시 실제 매니저·공 객체·자원·체력·생산 진행률·타이머를 복구하며 경험치/보상이 없습니다. 연습 중 새로고침하면 마지막 실제 왕국을 복원합니다.
- **군사 도전:** 실제 병력 사망, 유지비와 경험치가 적용됩니다. 진행 상태·투사체·체력·유료 대기열을 저장하고 이어갑니다. 최초 승리 보상은 한 번이며 경험치는 시나리오별 첫 도전에서 병사당 최대 100입니다. 재시도 성장 반복을 제한합니다.
- 경제 payload **v4**, 기존 저장 키 유지, v1/v2/v3 자동 이행. 손상된 군사 필드는 안전한 기본값으로 정리합니다. 경로·렌더 객체·물리 body는 저장하지 않습니다. 수치 변경과 1초 군사 체크포인트를 저장하며 오프라인 자동 생산은 하지 않습니다.
- 결과에서 생존/손실/처치/스피어 피해/콤보/경험치/보상/병사별 피해·치유 기여를 확인합니다. 최근 도전 기록은 10개로 제한합니다.

주요 파일: `src/army/{ArmyManager,CombatManager,PathfindingSystem,SpatialGrid,FormationManager,DamageCalculator,MilitarySaveManager,ArmyRenderer}.ts`, `src/config/army.ts`, `src/ui/ArmyUI.ts`, `src/army.css`, `tests/army.test.ts`. 기존 `GameStateManager`, `EconomySaveManager`, 건물 설정, 오디오와 Phaser 장면에 연결했습니다.

### 개발용 군사 검증실

`npm run dev` 후 `/?military-lab=1`에서 명시적인 시험 데이터 버튼을 사용할 수 있습니다. 정상 자원 획득과 해금을 생략한 고급 기능 QA용이며, 실제 저장과 분리된 `sessionStorage`를 사용합니다. 20/50/100기 부하 프리셋은 정상 인구 상한을 초과할 수 있습니다. 실제 Phaser 렌더 완료 간격의 최근 약 2초 FPS/P95를 표시합니다. **프로덕션 빌드에서는 검증실 코드와 진입점이 제거됩니다.**

PHASE 5는 현재 병력·연구·건물 ID·전투 기록을 재사용하여 적 왕국 AI, 침공, 성문/성벽/왕궁 체력, 건물 파괴와 복구 비용, 전쟁 승패·영토 보상을 연결할 수 있습니다. 이번 단계에는 캠페인, 적 경제 운영, 실제 성 파괴, 멀티플레이를 구현하지 않았습니다. 아군 스피어 근접 통과 버프는 선택 확장으로 남겨두었으며 기본 공은 아군을 공격하지 않습니다.
