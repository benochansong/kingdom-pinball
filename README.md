# KINGDOM PINBALL

**Bounce, Harvest, Prosper!** — GREENWOOD KINGDOM에서 플레이하는 중세 판타지 핀볼. PHASE 1 코어 엔진과 PHASE 2 경제 발전 모드를 구현했습니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다. 개발에는 Node 24를 사용했습니다.

```sh
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 엽니다. 기본 주소는 `http://127.0.0.1:5173`입니다.

```sh
npm test
npm run typecheck
npm run build
npm run preview
```

`dist/`를 정적 호스팅에 배포할 수 있습니다. 서버·계정·외부 API가 필요하지 않습니다. 모든 그래픽은 Canvas, 사운드는 Web Audio로 생성합니다. 외부 폰트나 음원 요청이 없습니다.

## 조작

| 키                  | 동작                      |
| ------------------- | ------------------------- |
| A / ←               | 왼쪽 플리퍼               |
| D / →               | 오른쪽 플리퍼             |
| Space 누르기 / 놓기 | 발사 강도 충전 / 발사     |
| W                   | 흔들기 (쿨다운·TILT 적용) |
| Esc                 | 일시정지 / 재개           |
| R                   | 재시작 확인               |
| M                   | 음소거                    |

하단 포인터 버튼으로도 양쪽 플리퍼와 발사대를 조작할 수 있습니다. 포커스를 잃으면 자동으로 멈춥니다.

## PHASE 1

- 600×900 논리 좌표, 240Hz 고정 스텝 Matter.js 물리. 최대 속도와 프레임 누적 상한으로 충돌 안정성을 유지합니다.
- 회전축을 중심으로 움직이는 플리퍼. 회전 표면의 상대 속도와 접촉 법선으로 충격량을 계산합니다. 끝부분 타격이 강하며 조준 방향은 접촉 지점과 타이밍에 따라 달라집니다.
- 오른쪽 스프링 발사대, 상단 유도 통로, 역류 방지 게이트, 슬링샷, 비대칭 범퍼 6종.
- 5개 스피어, 손실·재생성, 게임 오버, 재시작, TILT, 공 끼임 자동 복구.
- 점수 콤보, 4종 범퍼를 맞힌 후 활성화되는 보물 상자, 왕궁 5회당 +3,000점.
- 한국어 UI, 튜토리얼, 최고/최근 기록, 버전이 있는 오류 복구형 LocalStorage 저장.
- 음악/효과음 개별 음량, 음소거, 잔상/파티클/화면 진동 설정.
- 프로시저럴 왕국 테이블, 성벽, 왕궁, 숲·광산·수정, 금속 스피어와 충돌 효과.

## 구조

```text
src/
  core/       게임 상태, 타입이 지정된 충돌 이벤트 버스
  physics/    Matter.js 월드, 회전 플리퍼 접촉 계산
  systems/    점수, 콤보, TILT, 복구, 저장
  economy/    자원 거래, 생산, 시장, 목표, 발전 등급, 경제 저장
  scenes/     Phaser 렌더링, 독자적인 Canvas 테이블 아트
  audio/      Web Audio 음악·효과음
  effects/    제한된 파티클, 점수 팝업, 잔상
  ui/         HTML HUD, 메뉴, 모달
  data/       테이블 정의, 문자열, 튜토리얼
  config/     물리 밸런스
tests/        모델·물리 회귀 테스트
```

물리·게임 규칙·렌더링을 분리했습니다. `EventBus`의 유효 `hit`/`production` 이벤트가 이후 건설/전투 기능의 연결 지점입니다. 벽의 위치, 범퍼 점수, 물리 설정은 데이터 파일에서 조정합니다. 경제 밸런스는 `src/config/economy.ts`, 경제 목표는 `src/economy/ObjectiveManager.ts`에서 관리합니다.

## 두 가지 모드

**CLASSIC PINBALL**은 5개의 공으로 점수에 도전합니다. 경제 HUD와 비용이 없으며 기존 최고 점수·최근 원정·설정을 그대로 유지합니다.

**KINGDOM DEVELOPMENT**는 NEW KINGDOM으로 시작하고 CONTINUE KINGDOM으로 이어갑니다. 새 왕국은 확인 후 기존 왕국을 기록에 보관하고 초기화합니다. 최근 10개 왕국의 발전 기록을 별도로 확인할 수 있습니다.

### PHASE 2 구현

- 여섯 자원과 고유 시설: 벌목장, 채석장, 금광, 농장, 마력 수정탑, 코어 충전소.
- 접촉 법선 방향의 상대 속도에 따른 다섯 단계 생산 강도. 접근 속도 40px/s 이하와 유효하지 않은 충돌은 생산하지 않습니다.
- 점수와 독립적인 4초 생산 콤보, 특수 생산 콤보 5종, 생산 이벤트 5종, 왕궁의 ROYAL PROSPERITY.
- 시설별 READY/ACTIVE/BONUS/OVERLOADED/RECOVERING 상태. 반발 물리는 유지하면서 과부하 시 생산량 감소.
- 시설 1~5레벨, 레벨별 그래픽 장식·생산량 변화, Lv.3 회복 가속, Lv.4 과부하 저항.
- 창고 1~5레벨, 용량 초과 차단, 80% 안내와 초과 생산량 통계. 코어 에너지는 별도 용량.
- 왕실 시장의 1회·5회·최대 거래, 비용/수령량 미리 보기, 전체 거래 조건을 확인한 후 원자적으로 반영.
- 코어 에너지 재발사, 금화/마력석 복구, 자원이 모두 부족하면 경제 결과 화면.
- 5단계 왕국 발전 등급, 13개 경제 목표와 한 번만 수령하는 보상, 최근 자원 내역·생산 통계·플레이 스타일.
- 모든 관리 메뉴에서 물리, 콤보, 이벤트, 과부하, 쿨다운 시간이 함께 정지.
- 시설별 파티클, 획득량 팝업, HUD 이동 효과. 그래픽 효과는 물리 객체와 분리.
- 실제 행동에 반응하는 경제 튜토리얼, 다음 안내/건너뛰기/다시 보기.
- 작은 화면에서는 측면 패널을 숨기고 **왕국 현황**에서 등급·콤보·목표·특수 콤보에 접근합니다. 물리 좌표는 변하지 않습니다.

### 초기 밸런스

| 자원        | 초기 보유 | 초기 용량 | 일반 강도 기본 생산 |
| ----------- | --------: | --------: | ------------------: |
| 목재        |        50 |       500 |                  10 |
| 석재        |        30 |       500 |                   8 |
| 금화        |        50 |     1,000 |                   6 |
| 식량        |        30 |       500 |                  12 |
| 마력석      |         0 |       100 |                   3 |
| 코어 에너지 |       100 |       100 |                   5 |

- 첫 발사는 무료. 손실 후 버튼을 눌러 에너지 20을 소비합니다. 에너지 부족 시 금화 30 또는 마력석 8로 에너지 20을 회복합니다.
- 시설 강화 비용: 목재/석재/금화 각각 `50/30/40 → 100/70/80 → 200/140/160 → 350/250/300`.
- 시설 배율: `1 / 1.25 / 1.6 / 2 / 2.5`. 창고 용량 배율: `1 / 2 / 4 / 7 / 10`.
- 생산 강도 배율: `0.5 / 1 / 1.25 / 1.5 / 2`, 상대 법선 속도 경계 `180 / 420 / 700 / 1000px/s`.
- 생산 콤보: `1~2 ×1, 3~4 ×1.2, 5~9 ×1.5, 10~19 ×2, 20+ ×3`. 레벨·강도·콤보·이벤트를 곱한 **최종 배율 상한은 ×8**입니다. 최종 지급은 정수 내림입니다.
- 시설 생산 대기시간 420ms. 기본 과부하는 8초 안에 7회, 회복 7초, 생산량 25%. Lv.3부터 회복 시간 20% 감소, Lv.4부터 허용 타격 +3.
- 특수 콤보 공통 재사용 20초. MINING MASTER는 다른 생산시설 없이 채석장↔금광을 교대로 4회, HARVEST FESTIVAL은 12초 내 농장 5회, KINGDOM PROSPERITY는 15초 내 여섯 시설입니다.
- 유효 생산 18회, 특수 콤보 또는 목표 보상이 생산 이벤트를 유발합니다. 동시에 하나만 활성화되며 왕궁 보너스는 15초 지속 시간을 갱신합니다.
- 발전 등급용 누적 생산은 **실제 저장된 시설 생산량**입니다. 시장 구매·특수 보상·창고 초과분은 포함하지 않습니다.

### 저장과 이어하기

클래식 `kingdom-pinball:v1`과 경제 `kingdom-pinball:economy:v2`를 별도로 저장합니다. 경제 v1 필드 마이그레이션, 잘못된 값 정리와 기본값 복구를 지원합니다.

경제 모드는 유효 생산, 강화, 거래, 목표 보상, 발사/손실/재발사와 5초 체크포인트마다 저장합니다. 공의 좌표는 복원하지 않습니다. **발사 전 `inflight` 상태를 먼저 저장하므로 비행 중 새로고침하거나 메뉴로 나갔다 이어하면 공 손실로 처리되고 유료 재발사가 필요합니다.** 이미 비용을 낸 발사 대기 상태는 다시 비용을 내지 않습니다. 정상적인 끼임 복구·발사 통로 회수는 무료입니다.

다른 탭에서 저장이 변경되면 기존 탭을 일시정지하고 최신 저장을 불러오도록 안내합니다. 계정·클라우드 저장 기능은 없으며 브라우저 데이터를 지우면 기록이 사라집니다. 개발자 도구로 LocalStorage를 직접 변조하는 행위까지 막는 서버 기반 보안은 제공하지 않습니다.

## 검증과 한계

상세 실행 결과는 [docs/VALIDATION.md](docs/VALIDATION.md)를 참고하세요. PC 브라우저가 우선 대상입니다. 390×844 브라우저 화면 배치는 확인했지만 터치 입력은 보조 기능이며 모바일 실기기 최적화는 별도 검증이 필요합니다. 렌더링은 60FPS를 목표로 하지만 여러 하드웨어에서 성능 벤치마크한 결과는 아닙니다. 정밀 캐치·패스의 난이도와 1~20분 경제 성장 속도는 사용자 플레이테스트로 계속 조정해야 합니다.

장시간 프레임 정지 후에는 최대 150ms만 시뮬레이션해 과도한 따라잡기를 방지합니다. 따라서 백그라운드/성능 저하 중 현실 시간과 게임 시간이 다를 수 있습니다.

## 도메인과 배포

현재 게임은 상대 경로로 실행되어 도메인 설정이 필요하지 않습니다. 개발 도메인은 소스에 하드코딩하지 않습니다. 향후 절대 URL·OAuth·서버 기능을 추가할 때 `APP_DOMAIN`/`APP_ORIGIN` 기반 중앙 설정과 `.env.example`, 배포 환경 변수 문서를 함께 추가해야 합니다. DNS나 프로덕션 라우팅은 이 작업에서 변경하지 않습니다.

## 이후 확장

PHASE 3에서는 `ResourceManager.transact()`를 건설 비용에 연결하고 발전 등급을 건물 해금 조건으로 사용할 수 있습니다. 이후 BuildingManager, ArmyManager, BattleManager는 유효 충돌 이벤트와 자원 인터페이스를 재사용하면 됩니다. 건물 자유 배치, 물리 지형 변경, 군대·공성전, 캠페인, 특수 스피어와 멀티플레이는 이번 구현에 포함하지 않습니다.
