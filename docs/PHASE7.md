# PHASE 7 — CAMPAIGN WORLD

## 1. 실제 캠페인 기능

기존 전쟁·경제·건설·군사·마법 엔진 위에 독립 캠페인 프로필과 전투 세션을 추가했습니다. 월드맵 → 준비 → 목표 달성/실패 → 별·보상 → 영토 관리 → 다음 원정으로 이어집니다. 목표는 실제 생산, 건설, 성벽/왕궁 피해, 호위 이동, 장치 사용, 보스 체력으로 판정합니다. 전투 결과만 표시하는 가짜 완료 버튼은 일반 게임에 없습니다.

## 2. 지역 및 스테이지

8개 지역, 24개 스테이지입니다. 발전·방어·자원·공성·호위·구출·생존·정복·마법 장치·보스 목표를 사용합니다. 각 지역의 A/B 스테이지를 완료한 뒤 C 보스에 도전합니다. 방어/생존은 준비 시간 이후 9분, 일반 제한은 15~25분, 최종 보스는 35분입니다. 이는 목표 설정이며 모든 난이도의 정상 수동 플레이 시간·승률을 보증하지 않습니다.

## 3. 지역별 물리 환경

| 지역 | 실제 장치와 물리 |
| --- | --- |
| 초록 평원 | 표준 물리, 정찰/목재 목표 |
| 검은 숲 | 근접 공이 있으면 멈추는 회전 가지, 감속 안개 구역, 정찰 수정 |
| 철의 산맥 | 중력 1.1배, 금속 범퍼, 회전 광산 장치 |
| 황금 사막 | 마찰 1.5배, 모래 감속, 일정 방향 바람, 오아시스 |
| 얼어붙은 왕국 | 마찰 0.35배, 얼음/눈 구역, 3회 타격으로 파괴되는 얼음 |
| 화산 제국 | 마찰 0.9배, 2초 예고 후 분출, 회전 암석 |
| 마법 왕국 | 마찰 0.8배, 출구 충돌을 검사하는 쌍 포털, 간헐적 중력장, 룬 목표 |
| 암흑 제국 | 보스 단계에 따라 게이트/수정, 포털/중력, 열기 구역 전환 |

공은 최대 10개, 속도 상한 1,380px/s와 기존 240Hz 물리를 유지합니다. 포털은 다른 공·건물과 겹치는 출구를 거부하고 2초 재진입 제한을 둡니다. 장치/출구 공간은 건설과 설계도 검증에 포함합니다. 모래에서 완전히 정지하지 않도록 최소 탈출 속도를 부여합니다.

## 4. 지역별 보스

남작은 유료 기병 지원, 그림자 군주는 제한 분신·안전 위치 이동·정찰 약점, 철 거인은 장갑과 두 번의 제한 수리, 태양 파라오는 태양석 약점·수비대, 서리 여왕은 유료 성벽·냉기, 용은 예고 숨결·얼음/공성 약점, 대마법사는 속성 보호막·룬 약점을 사용합니다. 암흑 황제는 체력에 따라 5단계로 바뀝니다. 공격 전 3초 예고가 있으며 소환 총량은 12기로 제한합니다. 모든 보스는 일반 병력과 스틸 공으로도 피해를 줄 수 있습니다.

## 5. 월드맵과 해금

SVG 지도 이동·확대/축소·키보드 선택, 지역 설명, 단계/별/코어 진행률을 제공합니다. 초록 평원 다음 검은 숲 또는 철의 산맥을 선택합니다. 둘 중 하나를 정복하면 사막/서리, 4개 코어면 화산/마법, 앞선 7개 코어면 암흑 제국이 열립니다. 이야기 창은 건너뛸 수 있습니다. 별 조건과 패배 조건은 출격 전에 표시합니다.

## 6. 영토와 영구 성장

8종 특산물과 코어, 8단계 명성, 영토별 행정/생산/수비/교역/연구 1~5단계를 저장합니다. 첫 승리 보상, 첫 3회 재승리의 제한 특산물, 스테이지별 최대 20승까지의 연구/성장 턴을 제공합니다. 별 개선도 제한 보상을 줍니다. 시간 경과만으로 보상이 생기지 않습니다. 교역은 5→2~3, 경로당 턴 3회, 최대 8경로이며 자동 교역을 켜거나 끌 수 있습니다. 선택 반격전은 무시해도 영토를 잃지 않습니다.

## 7. 연구·장군·장비

5개 연구 계열에 30개 항목, 각 3단계입니다. 실제 생산·저장·병종 피해·수리 비용·발사력·에너지·마법 연구에 적용합니다. 장군 6명과 장비 6개/4슬롯은 획득 지역과 비용/능력 조건을 검사합니다. 지역 정복으로 병종과 마법을 해금하지만 전투 내 시설·왕국 등급 조건도 충족해야 합니다. 선택한 마법과 건설 설계도는 다음 원정에 가져오며 설계도는 실제 자원을 지불합니다.

## 8. 저장

`kingdom-pinball:campaign:v1:0`, `:1`, `:2`의 3개 독립 슬롯입니다. 이름·난이도·영구 성장·현재 전투·보스 체력/단계/예고·호위 진행·보상 처리 여부를 검증해 복원합니다. 덮어쓰기는 명시적인 슬롯 확인 버튼을 거칩니다. 다른 창의 변경은 오래된 저장을 차단하고 재불러오기를 안내합니다. 전투 결과 저장과 보상 사이에 중단돼도 결과 ID로 한 번만 정산합니다. 진행 중 멀티볼은 Phase 6의 지불된 안전 체크포인트 정책을 따릅니다.

## 9. 기존 기능과 엔딩

클래식·왕국 발전·자유 전쟁·훈련의 기존 저장 키는 변경하지 않습니다. 현재 지역의 물리/이벤트만 활성화하며 지도 복귀 때 제거합니다. 8코어를 모으면 8단계 엔딩, 전체 통계, 정예 재전, 72별/최고 난이도 도전, 빈 슬롯 NEW GAME PLUS가 열립니다. NG+는 완료 슬롯을 보존하고 일부 1단계 연구·장군·장비를 가져갑니다.

## 10. 주요 파일

`src/campaign/*`, `src/config/campaign.ts`, `campaignGrowth.ts`, `terrain.ts`, `src/ui/CampaignUI.ts`, `src/campaign.css`, `src/dev/CampaignLab.ts`. 공통 엔진에는 세션 확장 훅, 보스 최대 체력, 환경 건설 검사, 병종 잠금, 왕궁 성장 보존을 추가했습니다. 병력 그래픽은 방향/동작별 원본 도형을 유한한 스프라이트 캐시로 재사용하고 이미지 객체를 풀링합니다. 경로 탐색은 256개 유한 캐시와 고정 크기 큐를 사용합니다.

## 11. 실제 테스트

자동 테스트는 첫 지역 전체, 24개 목표 경로, 양쪽 분기, 8지역 10공/속도/정리, 8보스 예고/체력 복원, 황제 5단계, 막힌 포털, 저장 충돌, 중단된 결과 복구, 연구/교역/장비/왕궁 성장 보존을 포함합니다. 시간을 가속하거나 적을 직접 타격한 테스트 픽스처가 포함되며, 24개를 정상 조작으로 완주한 수동 테스트는 아닙니다.

Chromium 실제 UI에서 빈 슬롯 생성 → 지도 → 준비 → 전투 → 발사/생산 → 지도 저장 → 이어하기를 확인했습니다. 390×844 지도/버튼/이어하기에서 가로 넘침이 없었습니다. 개발 검증실의 8지역 전환·10공·대규모 병력·보스 렌더와 최종 콘솔 오류 없음도 확인했습니다. 수동 테스트의 QA 슬롯은 실제 사용자의 기존 슬롯을 덮어쓰지 않았습니다. 최종 전체 테스트/빌드 결과는 `VALIDATION.md`에 기록합니다.

## 12. 성능

`campaign-performance.json`의 Node 측정은 지역별 5초 가상 전투, 시작 10공+151기(보스 포함)의 CPU 시간이며 렌더 FPS가 아닙니다. 도중 손실과 사망으로 부하가 변합니다. 개발 브라우저의 초기 표본은 1공/0기 65FPS, 3공/50기 23FPS, 10공/150기+보스 4~5FPS로 목표에 미달했습니다. 이후 병력 검색/스프라이트 캐시 최적화를 적용했으나 재측정에서 약 1초 간격 프레임 스로틀링이 발생해 최종 렌더 성능 개선율을 확정하지 않았습니다. **대규모 60FPS 달성을 주장하지 않습니다.** `?campaign-lab=1`은 개발 서버 전용이며 세션 저장을 분리합니다.

## 13. 미구현/간소화

보스의 전용 대형 애니메이션 대신 기존 병종 실체와 이름·링·용의 날개·예고를 사용합니다. 서리 성벽은 실제 공용 성벽, 대마법사 발전기는 룬 약점 목표로 표현합니다. 지역 아트는 공용 테이블 위에 서로 다른 지형 도형·장치·색을 추가하고 음악은 원본 합성 선율의 음역/템포/음색 및 보스 리듬을 변형합니다. 외부 상용 그래픽/음원은 사용하지 않았습니다. 영화식 엔딩 영상 대신 순차 표시 연출입니다.

## 14. 발견한 오류와 남은 제한

초기 건설 공간을 막던 지역 목표 위치, 설계도 환경 검사 누락, 성장 왕궁 체력 복원, 오래된 창의 저장 덮어쓰기, 결과 재진입의 보상 누락, 빠른 경로의 수송대 정지, HUD 갱신 중 클릭 손실을 수정했습니다. 장시간 정상 플레이 밸런스, 모든 난이도/장군 조합 승률, 실제 모바일 멀티터치, Firefox/Safari, 청감, 수시간 메모리/GC 검증은 미수행입니다. 로컬 저장은 서버 검증/부정행위 방지 체계가 아닙니다.

## 15. 다음 단계

사용자가 이어서 요청한 Phase 8은 독립 생존·샌드박스부터 검증하고 보스 러시·퍼즐·로그라이크·테이블 제작·날짜 도전·프로필을 확장합니다. 이 문서는 Phase 7 완료 시점의 범위를 기록합니다.
