### 성능 측정

Node 측정은 렌더 없이, **추가 정적 시험 건물 20개 + 혼합 병력 + 적군 + 240Hz Matter/20Hz 전투**로 가상 10초를 실행했습니다. 부하용 건물 배치는 정상 사용자 배치 안전성을 보증하는 설계가 아닙니다. 단일 실행값으로 하드웨어별 보장은 아닙니다.

| 아군 수 | 전체 CPU 시간 | 60Hz 묶음 P95 | Matter body 수 |
| ---: | ---: | ---: | ---: |
| 20 | 347.0ms | 2.01ms | 46 |
| 50 | 430.9ms | 2.72ms | 46 |
| 100 | 763.0ms | 4.85ms | 46 |

실제 Chromium/Phaser의 최근 약 2초 렌더 간격 표본(추가 병영 1개, 비전투 집결, 1250×712 내외): 20기 **83FPS/P95 16.7ms**, 50기 **58FPS/23.2ms**, 100기 **33FPS/34.1ms**. 390×844의 100기 표본은 **23FPS/42.9ms**였습니다. 렌더 목표 60은 강제 FPS 제한이 아니므로 고주사율 환경에서 60을 넘을 수 있습니다. 도구 조작과 디스플레이 조건에 영향을 받는 짧은 표본이며 지속 평균이나 실기기 보장은 아닙니다. **100기에서 60FPS는 달성하지 못했습니다.** 병력 수가 늘어도 Matter body는 늘지 않으며 물리 정밀도는 낮추지 않았습니다.

Phase 4 시점의 남은 검증: 1~20분 정상 성장 밸런스, 모든 병종/진형 조합의 승률, 저사양 실기기/Firefox/Safari, 장시간 메모리·GC, 오디오 청감. 선택 사양인 아군 스피어 통과 지원 효과는 미구현입니다.
