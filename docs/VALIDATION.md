# 실행 검증 기록

검증 환경: Windows, Node.js 24.14.0, npm 11.9.0. 날짜: 2026-11-26 (Asia/Seoul).

- `npm install`: 성공, 취약점 0개.
- `npm test`: 13개 통과.
- `npm run build`: TypeScript 검사와 Vite 프로덕션 빌드 성공.
- `npm run dev`: Vite 서버 실행 확인.
- 실제 Chromium 브라우저: 타이틀/테이블 표시, Space 충전 발사, A/D 입력, 숲 타격 점수 200점, 손실 후 잔여 공 4개 및 재생성 확인.
- 실제 브라우저: Esc 일시정지, 설정 모달, 음소거 변경, R 확인 후 재시작, 최고 점수/최근 기록 유지 확인.
- 실제 브라우저 콘솔: 확인 시점 error/warn 0개.

자동 테스트: 콤보 전체 배율·만료, 범퍼 중복 억제, 왕궁 보너스, 보물 해금, 손상/차단 저장소, 30/60/144FPS 동일 궤적, 발사 통로와 게이트, 최고속 벽 충돌, 플리퍼 기저/끝부분 반응 차이, 충전·일시정지, 5회 손실·종료, TILT와 새 공 리셋, 끼임 감지·캐치 제외, 30회 반복 재시작 정리.

테스트 중 수정한 결함: Matter.js 공 생성 시 정적 상태로 생성하면 질량 복구가 불가능했던 문제, 발사대 유도 레일 끝부분이 통로를 막던 문제.

아직 검증하지 않은 항목: 여러 실제 기기/브라우저 성능, 소리의 청감 평가, 장시간 숙련자 캐치·패스 난이도, 수시간 메모리 프로파일링. 자동 테스트가 해당 항목의 사용자 플레이테스트를 대신하지 않습니다.
