# Phase 6 — Magic & Multiball

## 1. 실제 구현
기존 240Hz Matter 테이블에 최대 10개의 독립 공을 연결했습니다. 고유 논리 ID, 주 공 승계, 개별 복구, 공유 플리퍼, 효과 시간·비용·쿨다운을 사용합니다. 클래식은 기존 규칙을 유지합니다.

## 2. 스피어 10종
스틸, 화염, 얼음, 번개, 공성, 폭발, 치유, 황금, 유령, 혼돈. 전환은 동일 Matter body의 밀도·반발·마찰을 기준값에서 변경하며 위치·속도·각도·ID를 유지합니다. 화염은 4초 최대 3중첩, 냉기는 돌격 취소와 최대 1.5초 빙결, 번개는 제한된 비재귀 연쇄, 공성은 시설 보너스, 폭발은 5회 타격 후 스틸 복귀입니다. 치유는 살아 있는 아군·시설에 제한된 회복, 황금은 생산 보너스, 유령은 적 방어시설 한 번의 충돌만 통과, 혼돈은 제한된 속성 선택입니다.

## 3. 비용과 연구
마법 충전, 마력석, 코어 에너지를 분리합니다. 5개 연구 계열과 1–3단계 연구, 실제 왕국 등급·시설 조건, 자원 선지불을 적용합니다. 시설 파괴 시 해당 연구가 멈추며 능력 사용이 잠깁니다. 원소 대장간·신비 도서관·분열 제단·폭풍 오벨리스크를 기존 건설 카탈로그에 추가했습니다.

## 4. 주문
화염 폭풍, 냉기 장막, 연쇄 번개, 왕실 보호막, 신성한 빛, 대지진. 자동 조준은 실제 대상 밀집도/회복 대상에 기반하며 수동 모드에서는 테이블 범위를 표시합니다. 취소·무효 대상·준비 보호 시간에는 지불하지 않습니다. 왕궁 보호 규칙을 재사용합니다.

## 5. 속성 콤보
열충격, 분쇄, 과부하, 방어 파괴, 신성 수호, 번영, 원소 격노. 조건 소비와 개별 15초 대기로 연쇄 재귀 및 무료 반복 발동을 막습니다.

## 6. 멀티볼
연구 I/II/III는 3/5/7개 공, 15/20/25초입니다. 강철·화염·냉기·번개·공성·황금·혼합형을 선택합니다. 추가 공의 생산/피해는 단계별로 감소하며 시설 타격 충전 쿨다운은 공유됩니다. 주 공 손실은 생존 공에 승계하고 마지막 공 손실만 에너지를 소모합니다.

## 7. CORE STORM
15초, 최대 10개, 순차 안전 생성, 마력석 25(효율 연구 적용), 사기와 군대 공격 보너스, 생산 20% 증가. 기본 혼합과 여섯 변형을 제공합니다. 최초 5초 안에 최대 5회 공 구제, 마지막 3초 표시, 종료 시 주 공 한 개와 쿨다운을 남깁니다.

## 8. 적 마법
적의 실제 시설·마력석·가상 생산 타격으로 쌓은 충전·연구를 사용합니다. 세력별 주문 선호와 3초 예고 후 재검증하며 시설 파괴로 발동이 취소됩니다. 저항은 연구와 세력 계수로 제한됩니다.

## 9. 조작과 표현
ZXCV 스피어, G/H 주문, J 멀티볼, K 궁극기, Tab 마법 관리. M은 기존 음소거, 전쟁 지휘소는 L로 이동했습니다. 4개 공/2개 주문 편성과 4개 프리셋, 연구·업적·통계·13단계 안내, 터치 버튼을 제공합니다. 서로 다른 색·기호, 주 공 윤곽, 짧은 잔상, 최대 48개 마법 효과와 원본 합성 사운드를 사용합니다. 버튼 DOM을 보존해 HUD 갱신 중 클릭이 끊어지는 문제를 수정했습니다.

## 10. 훈련
6개 시나리오는 메모리 전쟁 저장소와 가상 자원으로 실행됩니다. 원래 물리 엔진·왕국·병력·마법 객체와 시간을 보존하여 복귀합니다. 완료 기록만 별도 `kingdom-pinball:magic-training:v1`에 저장합니다. 실제 전쟁 기록·성장·보상에 합산하지 않습니다.

## 11. 저장
기존 경제 v4/전쟁 v1 데이터에 선택적 magic v1 필드를 추가했습니다. 이전 저장을 삭제하지 않습니다. 연구·지불·게이지·효과·편성·쿨다운·통계를 검증해 복원합니다. 진행 중 멀티볼은 이미 지불된 안전 체크포인트로 종료하고 재사용 대기를 남기며 마력석이나 게이지를 환급하지 않습니다.

## 12. 주요 파일
`src/config/magic.ts`, `src/magic/*`, `src/ui/MagicUI.ts`, `src/ui/patchHTML.ts`, `src/magic.css`, `PinballPhysics`, `GameStateManager`, 전투/경제/전쟁 연동, `tests/magic.test.ts`.

## 13. 실제 검증
전체 142개 테스트(8파일) 통과. 마법 28개에는 10종 전환, 6주문 지불·쿨다운, 무효 대상, 연구 중단·재개, 6훈련 원본 복원, 중복 손실, 저장 재진입, 10공 상한/5구제, 일시정지와 속도 제한이 포함됩니다. npm install 성공(감사 취약점 0), TypeScript 및 프로덕션 빌드 성공, Vite 실행 성공.

Chromium에서 훈련 진입→발사→3공 멀티볼/10공 STORM→목표 달성, 마력석 지불·게이지 감소, 마법 편성 화면, 훈련 종료 후 메뉴 복귀를 확인했습니다. 최종 검증 콘솔 오류 없음. 실제 모바일 기기나 모든 주문의 장시간 수동 조작 검증은 수행하지 않았습니다.

## 14. 성능과 제한
`magic-performance.json`은 1공/50기, 3공/50기, 5공/100기, 7공/100기, 10공/150기의 5초 가상 전투 CPU 측정입니다. 렌더 FPS가 아니며 도중 손실·사망으로 부하는 달라집니다. Phase 5의 100/150기 브라우저 60FPS 미달은 해소되었다고 주장하지 않습니다. 저사양·장시간 GC·모든 마법 조합의 승률/청감 검증이 남아 있습니다. 혼돈구는 무작위 속성 효과를 제공하며 별도 무작위 물리 배율은 적용하지 않습니다. 시설 치유는 살아 있는 시설에만 소량 적용합니다.
