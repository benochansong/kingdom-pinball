# PHASE 11.1 — 반복 측정

2026-11-27. 수정 전/후 각 4,800회: 3개 기본 목표물 테이블 × 4개 입력 정책 × 4개 발사 강도 × 100개 시드. BALL SAVE/킥백 모두 꺼짐. Matter.js 실제 엔진 240 Hz, 회당 90초 상한. 건물·지역 장치·군대 없는 기본 목표물 배치 비교이며 사람의 실력 등급을 뜻하지 않는다.

원본: [수정 전](pinball-before.json), [수정 후](pinball-after.json), [전체 분류](pinball-comparison.json). 수정 전 엔진은 `b0c9be4`. `BALANCE_BASELINE=1` 환경 변수는 해당 버전과 같은 authored 물리 프리셋을 사용한다. 원래 수정 전 실행과 재측정 4,800회의 시간·플리퍼 타격·범퍼 타격이 모두 일치했다([대조 기록](pinball-baseline-verification.json)). 실행 명령은 [재현 절차](PHASE11_1.md#재현-명령)를 따른다. 도랑 구분은 실제 가이드 레일 바깥 진입을 추적하며 플리퍼 아래에서 중앙으로 이동해도 도랑 아웃으로 유지한다. 이 분류 기준을 수정 전후에 동일하게 적용했다. 초기 사각 영역 분류 실험값은 최종 비교에서 제외했다.

발사 강도는 ±3%p, 입력 높이는 ±12px의 고정 시드 변동. basic은 하단 745px 이후, timed는 705px 이후 120ms 유지하며, mirrored는 timed의 좌우 트리거 여유 오차 부호를 반전한다. 두 정책은 이번 표본에서 결과가 같았다. 전체 테이블을 좌우 반전한 실험은 아니다. 별도 자동 테스트에서 좌우 플리퍼의 대응 접점·속도 대칭을 검사한다.

**해석 주의:** 평균·중앙값은 발사부터 첫 드레인/회수/90초 종료까지의 관찰 길이이다. 회수 종료와 90초 검열을 포함하므로 완결된 평균 생존 시간이 아니다. 특히 무입력/일찍 올린 플리퍼 정책은 수동 바운스·캐치로 90초에 도달하는 비율이 높다. 오래 머무르는 것만으로 조작감이 좋아졌다고 판정하지 않는다. 90초를 넘는 최장 생존과 사람의 25–40/40–65/70–120초 목표 달성은 미측정이다.
