# PHASE 9 — Visual, Sound & Game Feel

## 1. 그래픽

기존 600×900 상단 시점과 240Hz Matter 물리를 유지했습니다. 원본 테이블의 석재 경계·성·금속 구체를 재사용하고 건물별 Canvas 텍스처, 지역별 장식, 그림자·측면·지붕, 횃불과 환경광을 추가했습니다. 공은 건물·마법보다 높은 레이어에 남습니다. 건물 겹침 시 지붕을 반투명하게 표시하며 실제 충돌 영역은 바꾸지 않습니다.

## 2. 핀볼 감각

충돌 속도에 따라 불꽃 수와 음높이·음량·저음이 달라집니다. 실제 타격 좌표에 반응 링을 표시하며, 자원 팝업은 실제 저장량이 0보다 클 때만 나타납니다. 스프링 압축·금속 플리퍼와 공의 원래 정확한 좌표를 유지했습니다. 최대 충전음, 콤보 단계 배너, 손실·구출 안내를 연결했습니다. 충돌을 강조하려고 시뮬레이션 시간을 멈추지 않습니다.

## 3. 건물과 병력

벌목장 통나무·도끼, 채석장/금광 지지대·광석, 농장 밀·풍차, 시장 차양·상품, 창고 상자, 대장간 굴뚝·불, 군사시설 무기대, 마법시설 수정·고리, 성/탑의 성가퀴를 구분합니다. 1–5레벨에 재질·깃발·금장·문장을 추가합니다. 건물 텍스처는 종류/레벨/진영별로 필요할 때 생성하여 재사용합니다.

8병종의 기존 방향별 스프라이트를 유지하면서 걷기·돌격의 움직임, 공격 궤적, 준비 고리, 피격·사망 입자와 2–5계급 표식을 보완했습니다. 실제 이동·피해·투사체 상태를 표현합니다. 별도 3D 모델이나 수작업 프레임 애니메이션을 제작한 것은 아닙니다.

## 4. 여덟 지역

초원/숲의 입체 나무, 산맥의 광석 구조물, 사막의 사원형 지형, 얼음 결정과 눈, 화산암·용암 균열·재, 비전 수정·빛, 암흑의 결정·비를 표현합니다. 90초씩 아침/낮/석양/밤이 순환하며 낮·석양·밤 고정도 가능합니다. 장식 날씨는 경제·중력·마찰에 영향을 주지 않습니다. 캠페인의 실제 환경 규칙은 별도로 유지합니다.

## 5. 전쟁과 파괴

실제 건물 체력 변화에서 한 번만 파편을 발생시키며, 체력 비율별 균열·불·연기와 붕괴 잔해를 표시합니다. 성벽 파괴의 BREACH와 왕궁 붕괴 표시는 기존 경로/충돌 제거 결과를 따릅니다. 파편에는 물리 body나 추가 피해가 없습니다. 실제 전쟁·모드 결과에 승패 음계를 연결했습니다.

## 6. 마법·CORE STORM·보스

화염·얼음·번개·치유 구체의 모양과 속성별 색, 주 공 외곽선, 상태 이상·실제 마법 범위 표시를 보완했습니다. CORE STORM 준비/발동/종료 배너와 테이블 가장자리 에너지 고리, 음악 리듬을 제공합니다. 전면 섬광은 사용하지 않습니다. 지역 보스에 날개·장갑·태양·수정 등의 표식을 추가했고 이름 배너는 비차단 방식으로 표시됩니다. 배너 때문에 전투 시간을 멈추지 않으며 ‘연출 건너뛰기’로 배너/카메라 효과를 취소할 수 있습니다.

## 7. UI

금속·왕실 금색 패널, 버튼 상태, 자원 SVG 아이콘, 모드 카드 대표 문양·최근 기록·이어하기 가능 여부를 통일했습니다. 현재 목표 한 개를 테이블 위에 표시합니다. 캠페인 지도에 강·호수·산맥·숲·사막·화산을 추가했고 기존 진행/줌/이동을 유지했습니다.

## 8. SIMPLE / ADVANCED

SIMPLE이 기본값입니다. 큰 화면에서 자원/생산을 왼쪽, 전쟁/모드/마법을 오른쪽에 두고 테이블 전체 높이를 확보합니다. 세부 메뉴는 계속 사용할 수 있습니다. ADVANCED에서는 기존 상세 측면 패널을 표시합니다. 퍼즐에서는 관계없는 전쟁·경제 HUD를 숨깁니다. 작은 창에서는 일반 세로 배치와 스크롤로 전환됩니다.

## 9. 음악과 효과음

MASTER, MUSIC, PINBALL, COMBAT, MAGIC, AMBIENCE, UI 채널을 분리했습니다. 기존 전체 효과음 음량도 유지합니다. 채널별 0% 음소거, 전체 음소거, 자동 재생 제한 대응, 동시 최대 32 voice와 채널 상한, 중요한 핀볼 음 우선, 출력 compressor를 적용합니다. 일시정지·메뉴 전환·종료 시 voice를 정리합니다.

평화/준비/전투/공성/왕궁 위기/폭풍/승패를 실제 상태로 선택하며 전환 유지 시간과 두 음악 버스의 gain crossfade를 사용합니다. 지역별 음역·템포·환경음을 제공합니다. 모두 Web Audio 합성음입니다. 녹음된 오케스트라·합창·성우 음원은 포함하지 않습니다. 외부 음원 메타데이터의 경로는 null로 두어 없는 파일을 요청하지 않습니다.

## 10. 품질과 접근성

LOW/MEDIUM/HIGH/ULTRA는 파티클 상한 32/70/120/160, 장식 수 8/18/30/48, 장식 갱신 간격 100/66/33/16ms와 그림자 밀도가 실제로 다릅니다. 자동 품질은 5초 창의 P95와 20초 이상 유지 조건으로 장식 품질만 한 단계 낮춥니다. 입력·물리 주기·보상은 변경하지 않습니다.

흔들림 강도, 섬광 감소, 파티클 밀도, 날씨, 밝은 조명 고정, 공 외곽선, 고대비, 문양, UI/글자 배율, 채널 음량, 주요 키 매핑, 전체 화면을 지원합니다. 중복/예약 키는 거부하며 포커스 상실과 전체 화면 종료 시 입력을 해제합니다.

## 11–12. 자산과 권리

[ASSET_LICENSES.md](../ASSET_LICENSES.md)에 실제 소스·사용 경로·외부 라이선스 여부를 기록했습니다. 추가 다운로드 이미지/폰트/음악 없이 원본 Canvas/Phaser/SVG와 합성음을 사용합니다. 시스템 폰트를 파일로 재배포하지 않습니다.

## 13. 주요 파일

- `src/presentation/`: 설정 이행, 품질/프레임 측정, 건물 텍스처와 세계 연출
- `src/ui/PresentationUI.ts`, `IconRegistry.ts`, `src/presentation.css`: 설정, HUD, SVG
- `src/audio/AudioManager.ts`, `MusicDirector.ts`: 믹서, voice 제한, 상황 음악
- 기존 Scene/Effects/Army/Magic/WarRenderer: 원래 판정과 연결
- `src/dev/VisualLab.ts`: 별도 저장을 쓰는 실제 렌더 검사 도구
- `tests/presentation.test.ts`, `audio.test.ts`: 설정/물리 독립성/오디오 정리

## 14. 검증

설정 이행·입력 중복 거부·품질 히스테리시스·동일 물리 결과·오디오 voice 상한과 정지를 자동 검사합니다. 기존 1–8단계 회귀 검사도 실행합니다. 최초 전체 실행의 두 실패는 CPU 경합에 따른 5초/30초 timeout이었고, 동시 worker를 2개로 제한한 관련 21개 재검사는 통과했습니다. 최종 전체 결과는 [VALIDATION.md](VALIDATION.md)에 기록합니다.

브라우저 검사 도구는 `/?visual-lab=1`에서만 노출됩니다. 실험용 보호/해금 설정이며 실전 승률 검사와 다릅니다. 원래 localStorage 키에 쓰지 않습니다. 측정 결과에는 종료·최대 공 수, 최대 병력, 파괴 수를 함께 기록하여 실제 조건을 확인합니다.

## 15. 성능

최종 실제 브라우저 원본은 `visual-performance.json`에 기록합니다. 평균뿐 아니라 P50/P95/P99와 표본 수를 포함합니다. 약 8초의 장면별 표본이며 지속 평균이나 최소 사양 보장이 아닙니다. 60FPS는 모든 조건에서 보장하지 않습니다. 초기 도구에서 7공 해금·인구 제한·준비 시간·측정 결과 패널이 시나리오를 방해한 문제를 발견해 수정했습니다. 해당 초기값을 최종 7공/대규모 전투 측정값으로 사용하지 않습니다.

## 16. 기존 기능 보호

240Hz 물리와 기존 충돌·경제·전투·마법·보상 규칙은 유지합니다. 설정은 기존 v1 저장의 별도 presentation 필드로 이행하며 캠페인/왕국/모드 저장을 초기화하지 않습니다. 기존 기능에서 발견한 샌드박스 전체 마법 해금 및 인구 슬라이더 적용 오류를 수정했습니다.

## 17. 제한

프로시저럴 2.5D 표현이며 완전한 3D·PBR·실시간 반사나 녹음 오케스트라가 아닙니다. 자동 품질은 장식 부하를 낮출 뿐 과도한 전투 CPU 부하를 해결하지 못합니다. 장시간 GPU 메모리 추적, 모든 물리 기기의 60FPS, 오디오 청감/기기별 믹싱 검수, 모든 전략의 수동 밸런스 검증은 완료하지 않았습니다. Phase 8의 60분 생존 시뮬레이션은 게임 로직 안정성 자료이며 60분 렌더 검증으로 간주하지 않습니다.

## 18. Phase 10 연결점

판정은 기존 순수 TypeScript 매니저에, 표시/오디오는 이벤트와 읽기 전용 상태에 둡니다. 그래픽 설정은 온라인 경쟁 능력치와 분리할 수 있습니다. 다음 단계에서 서버 물리, 명령 검증, 로비/영속 저장/재접속을 구현하며, 현재 로컬 기록을 신뢰 가능한 온라인 랭킹으로 전환하지 않습니다.
